# Trades Analyzer Simulator

A comprehensive React-based trading performance, analytics, and risk simulator.

## Features

- **Simulation Engine:** Accurately simulates P&L taking into account win rates, RR ratios, leverage, and charges.
- **Monte Carlo Analysis:** Calculates potential final bankroll scenarios simulating numerous equity curves.
- **Crypto & Index Ready:** Supports unique charges models for Crypto, Options, and regular Stocks.
- **Position Sizing:** Recommends Kelly Criterion lot sizes.

## Local Setup

1. `npm install`
2. `npm run dev`
3. Open `http://localhost:5173` in your browser.

## Tests

- Run `npm run test` or `npm test` to execute Jest assertions validating calculation integrity.
